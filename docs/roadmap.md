# Roadmap

## V1 Stabilization

- Improve active-vaulter tracking on crowded meet footage.
- Add manual athlete selection when multiple moving athletes are visible.
- Add better phase controls so coaches can drag phase boundaries.
- Add a saved calibration preset per venue/camera angle.
- Test on at least 20 real vault clips across side, oblique, front, and rear views.

## Ochy-Style Experience

- Add frame-by-frame issue cards tied to exact timestamps.
- Add before/after comparison between two vaults.
- Add athlete trend charts for approach rhythm, plant extension, knee drive, inversion, and clearance line.
- Add shareable coach reports.
- Add drills library mapped to each detected issue.

## Cloud/Product

- Add production Supabase project config.
- Add GoDaddy deployment checklist completion.
- Add team/coach account roles.
- Add privacy copy and terms for uploaded athlete videos.
- Add large-video upload progress and retry handling.

## Research

- Build a labeled vault clip dataset.
- Explore pole/box/bar detection.
- Compare MediaPipe with other pose models on pole vault footage.
- Investigate custom model training only after enough labeled clips exist.
